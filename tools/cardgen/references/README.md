# Drop design references here

This folder is for **visual examples you want future Añejo design work to learn from** — a
competitor post you liked, a layout mockup, a photo whose lighting is right, a card style
worth copying.

## How to add one

1. Drop the image in this folder. Any name is fine; a descriptive one helps
   (`methodology-dish-card.jpg`, not `IMG_4821.jpg`).
2. Add a short note beside it as a `.md` file with the same base name
   (`methodology-dish-card.md`) answering three things:
   - **What it is** and where it came from
   - **When we'd use this** (menu post? bowl breakdown? story?)
   - **What to copy and what to ignore** — the specific thing that makes it work

That note is the part that matters. An image with no note is a mood board; an image with a
note is a brief.

3. Commit both files.

## What this folder is NOT for

- **Brand voice, rules, claims, standards** → those go in `docs/brand-standards-brief.md`,
  which is compiled verbatim into every AI teammate's context.
- **Manuals, SOPs, licences, training docs** → upload those in the HUB at
  **Owner → Knowledge**, which chunks and indexes them so the Studio can answer from them.
- **Finished post images** → those live in R2 (`anejo-media`), not in the repo.

See `../README.md` for the generators, and `docs/MARKETING_TEAM_GUIDE.md` for the full map.
