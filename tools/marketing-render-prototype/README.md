## Preview and design

`output/workerd-cajita.jpg`: 1080×810 landscape, complete source image preserved in its original 4:3 aspect. Short edge headline plus exact repository emblem. No generated image content, object changes or crop occurs in this renderer. The current prototype adds a bounded translucent deep-green bottom scrim behind the caption and emblem; this visibly darkens that part of the original photo. Other aspect ratios use centered contain with a solid background, not stretched/cropped pixels. This is one fixed template with explicit text/emblem coordinates, not the full adaptive browser renderer. Visual review is required before use.

Source copies (unchanged bytes):
- `assets/source.jpg`: `public/assets/img/cajita/themes/anejo-signature-duo-v2.jpg`, 1448×1086 existing website theme asset. This establishes asset origin only; it is NOT evidence of authentic photographed food/event provenance. Do not use this example to claim an original event photograph or GBP eligibility.
- `assets/emblem.png`: `public/assets/img/emblem.png`, authentic repository brand mark.
- `assets/CormorantGaramond.ttf`: `tools/cardgen/fonts/CormorantGaramond.ttf`, fixed bundled variable TTF. `assets/OFL-CormorantGaramond.txt` is upstream Google Fonts OFL license. No runtime font network call or system-font dependency. Weight appearance and glyph shaping need visual comparison against Canvas; a requested SVG weight is not proof of exact variable-axis parity.

## Implementation

`core.mjs` initializes pinned resvg WASM, accepts guarded JPEG/PNG bytes, embeds bytes in SVG, retrieves RGBA directly, and encodes JPEG quality92. No intermediate PNG codec. Explicit `.free()` cleanup in finally for rendered image and renderer. Font, template and dependencies are pinned. `jpeg-encoder.mjs` is the license-retaining ESM adaptation of jpeg-js0.4.4 encoder (generated by `prepare-encoder.mjs`); returns Uint8Array without Node Buffer or global polyfills.

An initial named external-image `resolveImage` attempt returned a blank raster in this package/runtime. The retained implementation uses data URIs and tests pixel content to prevent silently accepting missing photos.

Guards: source <=5MiB, edges<=4096, decoded pixels<=4million; malformed/unsupported headers rejected before resvg. This is bounded format screening, not an exhaustive image security parser. No EXIF orientation normalization/ICC pipeline is implemented: first integration must accept normalized images or implement and test those cases. No remote/user-selected URL fetching exists. Arbitrary SVG is not accepted; text is escaped and length-limited. Generic placement is not safe for every photo; this template requires reviewed source/layout combinations.

The current fixed template adds a deterministic `#0A180C` gradient in the bottom 110 pixels only (y=700–810): transparent at its top, opacity 0.70 at 45%, and 0.78 at the bottom. It is drawn after the full-frame source and before the unchanged title/emblem. ## Measured headline rejection (local prototype, 2026-09-27)

`headlineBounds()` now measures the escaped headline with the pinned Cormorant font and resvg runtime before rendering the image composition. The fixed accepted text box is x=100–1037, y=710–780. Empty/unmeasurable text and measured bounds outside that box are rejected; the renderer does not shrink, wrap, crop or rewrite wording to force a pass. This closes a concrete gap: forty `W` characters passed the old character cap but reach the frame edge. Forty narrow `i` characters and the tested accented Spanish headings fit. The public render entry point invokes this guard and returns measured bounds as `headline` for inspection; temporary WASM measurement objects are freed even on rejection.

Validation: `node --test tools/marketing-render-prototype/test.mjs` — 8 tests passed locally, including oversized wording rejection, empty text rejection, Spanish examples, and successful rendering after a rejected attempt. Existing deterministic JPEG, source-content, PNG, token and scrim regressions pass. No image provider call, new package, deployment, production import, or customer-photo edit was made.

Limits: this is fixed-template glyph-bounds screening, not full browser typography parity, missing-glyph/font-coverage proof, food/packaging clearance, or arbitrary-photo approval. The added text-only WASM preflight has not been profiled against production CPU/memory budgets. Earlier resource numbers precede this guard. ## September27 protected-region guard (local only)

`render` accepts optional `protectedRegions` source-normalized `{x,y,w,h}` rectangles (maximum20). It validates finite coordinates and bounds, projects through the fixed contain scale/letterbox offsets and rejects intersections with measured headline, emblem or caption scrim before compositing. Geometry never certifies that an annotation covers all food or packaging. Missing/empty annotations report `protectionSource: visual_review_required`; even provided annotations retain `visualReviewRequired: true`. No photo detection, automatic approval, source-hash binding or production job integration is added.
