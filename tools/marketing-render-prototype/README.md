# Local editorial JPEG feasibility prototype

Local-only research, 2026-09-17. No app routes/imports, root dependency/configuration changes, production bindings, credentials, provider generation, publishing or deployment. `wrangler deploy --dry-run` below is a local build only. No paid resource was provisioned. This folder is not production-ready.

## Preview and design

`output/workerd-cajita.jpg`: 1080×810 landscape, complete source image preserved in its original 4:3 aspect. Short edge headline plus exact repository emblem. No generated image content, object changes, crop or repaint occurs in this renderer. Other aspect ratios use centered contain with a solid background, not stretched/cropped pixels. This is one fixed template with explicit text/emblem coordinates, not the full adaptive browser renderer. Visual review is required before use.

This establishes asset origin only; it is NOT evidence of authentic photographed food/event provenance. Do not use this example to claim an original event photograph or GBP eligibility.

## Implementation

`core.mjs` initializes pinned resvg WASM, accepts guarded JPEG/PNG bytes, embeds bytes in SVG, retrieves RGBA directly, and encodes JPEG quality92. No intermediate PNG codec. Explicit `.free()` cleanup in finally for rendered image and renderer. Font, template and dependencies are pinned. `jpeg-encoder.mjs` is the license-retaining ESM adaptation of jpeg-js0.4.4 encoder (generated by `prepare-encoder.mjs`); returns Uint8Array without Node Buffer or global polyfills.

An initial named external-image `resolveImage` attempt returned a blank raster in this package/runtime. The retained implementation uses data URIs and tests pixel content to prevent silently accepting missing photos.

Guards: source <=5MiB, edges<=4096, decoded pixels<=4million; malformed/unsupported headers rejected before resvg. This is bounded format screening, not an exhaustive image security parser. No EXIF orientation normalization/ICC pipeline is implemented: first integration must accept normalized images or implement and test those cases. No remote/user-selected URL fetching exists. Arbitrary SVG is not accepted; text is escaped and length-limited. Generic placement is not safe for every photo; this template requires reviewed source/layout combinations.

## Local workerd resource samples

With the existing root and prototype dependencies installed, run from the repository root:

```
node tools/marketing-render-prototype/resource-profile.cjs
```

The harness prints a unique temporary output directory containing its bundle, WASM, inspector target inventory and `measurements.json`; it writes no generated artifacts into the repository. It uses a loopback-only local runtime, explicitly selects `core:user:render-check`, records ten sequential fixed-fixture JPEG hashes and `Runtime.getHeapUsage` samples, and disposes the runtime. Connection, inspector commands, rendering and cleanup waits are bounded. Failures produce `error.json`; partial measurements are retained.

These are workerd inspector samples, **not Node RSS or a verified peak/all-inclusive isolate memory measurement**. Do not sum returned fields or compare `totalSize` directly with a production memory budget. Samples occur after requests; inspector attachment can change behavior. `initialGcAttempt`/`finalGcAttempt` record attempted garbage collection, including timeout: an `afterGcAttempt` sample does not establish that collection occurred. Local wall time is not billable CPU. This one fixture does not validate maximum input, concurrency, deployed cold starts, production limits, Canvas/brand parity, photo provenance or approval for publication. Application integration remains blocked on those separate checks.

## Fixed-template token alignment (local prototype, 2026-09-26)

The current prototype mirrors the browser renderer's `BRAND_INK.parchment` (`#E8E2CA`) for its title and `BRAND_INK.deep` (`#0A180C`) for the contain background. The headline keeps Cormorant Garamond weight 600. An executable test reads the browser token/font definitions and rejects drift. These values are mirrored locally; no production renderer or shared production module changed.

The original source remains fully contained, with the existing 1080×810 frame, title at (107,757), and unchanged authentic emblem asset at (43,717), 45×43. No crop, new overlay region, emblem redraw or image generation was added. Five prototype tests pass, including deterministic raster output and token drift checks. A local original-fixture render plus input/font/emblem/output hashes was saved at `/tmp/anejo-render-token-alignment-YhXQ5V` for review; temporary artifacts are not committed. Earlier `output/` images, hashes and benchmark numbers above are historical results from the preceding palette, not current-render acceptance evidence.

This is **token alignment, not full browser parity**. Browser Reposado profiles have different positions, glyph-width fitting, protected-area checks, sampled contrast, title halos, adaptive mark tint and sampled edge extensions. Those remain absent here. The fixed title crosses dark cloth onto lighter cloth in this one fixture: parchment is an approved ink but token membership alone does not prove adequate contrast. The original gold emblem is preserved; its appearance does not establish exact browser tint parity. Current output requires owner visual review. General source/headline combinations, maximum-width Spanish glyphs, packaging/food clearance and production resource limits remain unverified; do not treat the fixed layout as safe for arbitrary photos.
