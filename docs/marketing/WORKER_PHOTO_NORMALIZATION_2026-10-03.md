## Implemented path

The metadata reader preserves an original copy, checks PNG framing/CRCs and bounded RGB ICC structure, extracts a unique pre-image iCCP profile with keyword/compression validation, assembles bounded JPEG ICC segments, and strips ICC/EXIF only from the decoder copy. It rejects duplicates, conflicts, late declarations, malformed profiles, unsupported gamma/chromaticity/HDR/animation and JPEG XMP through the current admission guard. Inflated profile accumulation is capped at 64 KiB. DecompressionStream can emit a larger chunk before the check, so a hard peak inflation allocation bound is unverified.

The actual resvg decoder produces RGBA, the pinned LittleCMS kernel converts embedded RGB profiles to sRGB in batches while preserving alpha, orientation applies exactly once, and optional bilinear resizing preserves aspect within 2000×2000 without enlargement. Resampling uses premultiplied-alpha interpolation. A real translucent fixture initially failed: resvg pixels are premultiplied, so applying ICC directly darkened them. The decoder adapter now unpremultiplies before ICC conversion. This has unavoidable eight-bit rounding at low alpha and discards zero-alpha RGB; it is not lossless hidden-color preservation.

The deterministic PNG encoder emits explicit sRGB metadata, RGBA, CRCs and no original ICC/EXIF/GPS payload. A header readback checks dimensions, orientation and declared-sRGB status. The receipt includes original/derivative/profile hashes, source assumption, conversion performed, runtime/kernel versions, original orientation/dimensions, resize policy and output bounds. Untagged RGB is explicitly assumed sRGB; there is no fabricated ICC conversion. Output still requires visual review. This receipt is local evidence, not a production-persisted derivative authorization.
